One-line story: People (1) enter through the front door (2) into the office (3). The guard (4) stamps their ID card, and the office asks the records room (5) — which locks every drawer by school and role. Automatic jobs (6) keep data fresh and safe (8); watchdogs (7) alert us the moment anything breaks; the robot (9) tests every change before it can hurt the live system.

Key idea: the things that must never fail — isolation, accurate math, backups, alerts — are on timers and triggers, never on memory.

Rules that never bend: a student has one class per session (enrollments), one attendance row per day (attendance), one batch voucher per class per month (fee_vouchers), one marks row per student per entry (marks_records), one timetable slot per class per day (timetable_entries). The database enforces all of these.
