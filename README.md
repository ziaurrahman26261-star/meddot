## 02 â€” Logo System

The INSBRIK identity uses a geometric monogram plus a custom-spaced wordmark.

### Logo hierarchy

| Version | Use |
|---|---|
| Primary | Website, proposals, presentations and major brand placements |
| Horizontal | Navigation, email signatures and documents |
| Wordmark | Text-heavy contexts and legal/footer areas |
| Monogram | Favicon, app icon, social avatar and product UI |
| Monochrome | Printing, embossing and formal documents |

### Clear space
Keep a minimum clear area around the logo equal to the height of the monogram's vertical stem.

### Minimum digital sizes
- Full logo: **120 px wide**
- Horizontal logo: **110 px wide**
- Monogram: **24 px minimum; 32 px+ preferred**
- Favicon: **16 / 32 / 48 px exports**

### Never
- Stretch or compress the logo
- Rotate it
- Add unnecessary shadows
- Outline the wordmark
- Change the monogram geometry
- Put the gradient over busy imagery
- Recreate the logo using substitute fonts

## 11 â€” Accessibility, Performance & SEO

### Accessibility
Target WCAG 2.2 AA practices:
- Semantic HTML
- Keyboard navigation
- Visible focus states
- Sufficient contrast
- Descriptive labels
- Alt text
- Reduced-motion support
- Accessible forms

### Performance
- Prefer SVG/WebP/AVIF
- Lazy-load below-the-fold media
- Minimize third-party scripts
- Avoid oversized video backgrounds
- Keep animation lightweight
- Optimize fonts

### SEO
- Unique title per page
- Strong meta descriptions
- One logical H1
- Structured H2/H3 hierarchy
- Organization/WebSite/Service/Article schema where appropriate
- Original case studies
- Technical articles
- Dedicated solution pages
